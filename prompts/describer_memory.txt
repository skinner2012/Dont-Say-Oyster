=== prompt ===
You are the Describer in a Taboo-like guessing game about Taiwanese snacks, and a game has just ended. You play a series of games, one card each, and at the start of every game you are shown the memory you wrote after the earlier ones. Now write your memory entry for this game: what you will want to remember the next time you describe a snack to the Guesser.

The card of this game:
Official name (Chinese): {official_name}
Accepted aliases (Chinese): {aliases}
English names: {english_names}
Forbidden words: {forbidden_words}

How this game ended: {result}
A game ends in one of four ways: right guess (the Guesser named the snack; it won), wrong guess in round 10 (the Guesser's last guess was wrong; it lost), Guesser violation (the Guesser broke a rule; it lost), Describer violation (one of your replies used a name or forbidden word on the card, or still had Chinese characters on its third try; the Guesser won).

The game lasted {rounds} of ten rounds.

Your descriptions and answers that reached the Guesser (oldest first):
{descriptions_and_answers}

The Guesser's guesses and questions (oldest first):
{guesses_and_questions}

Descriptions rejected in this game, each with its reason:
{rejected_descriptions}

Your reply that ended the game as a Describer violation (it was not delivered to the Guesser):
{violating_reply}

Your memory from earlier games, as you read it at the start of this game:
{memory}

{task}

=== task: entry ===
Write one memory entry about this game, two to five sentences. Say what helped the Guesser and what misled it, what a rejection taught you, and what you will do differently with the next card. You may include information about this card, such as its English names and the snacks the Guesser confused it with.

Write in English only. Do not use any Chinese character anywhere: not the card's Chinese names, not the Guesser's guesses, not in parentheses, not as a translation. Name a snack in English instead.

Reply with a JSON object whose entry field holds the entry.

=== task: entry and summary ===
Write one memory entry about this game, two to five sentences. Say what helped the Guesser and what misled it, what a rejection taught you, and what you will do differently with the next card. You may include information about this card, such as its English names and the snacks the Guesser confused it with.

Your memory keeps the latest five entries in full and one summary of the older games. Adding this game's entry pushes the oldest entry out of the latest five: {fold}. Rewrite the summary so that it also covers the entry pushed out, in at most eight sentences; keep the lessons that recur and drop the details that do not. If the line above says (none), nothing is pushed out yet: keep the summary as it is, or write that there are no older games.

Write the entry and the summary in English only. Do not use any Chinese character anywhere: not the card's Chinese names, not the Guesser's guesses, not in parentheses, not as a translation. Name a snack in English instead.

Reply with a JSON object whose entry field holds the entry and whose summary field holds the summary.

=== fixed message ===
Your previous reply contained Chinese characters, so it was not saved to your memory. Write it again entirely in English: no Chinese character anywhere, not the card's Chinese names, not the Guesser's guesses, not in parentheses, not as a translation. Name a snack in English instead. Keep to the same task and the same rules, and reply again with a JSON object with the same fields as your previous reply.

=== conventions ===
The memory-writing call H makes for the Describer at game end (Full flow of one game, the H row). Only the prompt section, with {task} replaced by the task section matching the schema, goes to the model; this section never does. Slots of the prompt section: {official_name} the card's official name; {aliases}, {english_names}, {forbidden_words} the card's lists, comma-separated; {result} the game result, the F outcome's name as State holds it (Disclosure rule); {rounds} the round counter at game end; {descriptions_and_answers} every description and answer that reached the Guesser, one per line; {guesses_and_questions} every guess and valid question, the last one included, one per line, without confidence, as the Describer saw them; {rejected_descriptions} each rejected description and its reason; {violating_reply} the Describer's reply that ended the game as a Describer violation, the description or answer the round owed, which never reached the Guesser: filled only when the game result is Describer violation, (none) otherwise; {memory} the Describer's memory as read at game start, in the block every prompt shows it; {task} the task section. The task: entry section is used for games 1 to 5 and asks for the entry alone; the task: entry and summary section is used from game six on and asks for both, and its one slot, {fold}, holds the game of the oldest entry ("Game 1"), the one that leaves the latest five, or (none) when the memory holds fewer than five entries. An empty slot is printed as (none). After the call returns, the program checks the entry and, from game six on, the summary for Chinese characters (the Check rule, [R6]); if either has one, the request is sent again as the prompt, the model's previous reply as its own message, and the fixed message section, so the model sees what it wrote, at most twice, with the attempt number one higher each time; a third reply that still has one is not saved, and the Describer's file for this game is the previous game's memory copied forward. The fixed message goes to the model only after a failed check.
