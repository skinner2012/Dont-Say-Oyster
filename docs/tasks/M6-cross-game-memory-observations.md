## Describer (qwen3.8:27b, thinking medium): entries that match the record, one that stores a wrong lesson, two that credit a description the Challenger failed

Read against `runs/m6-t6/v3-game<n>.jsonl` (`rounds[].rejected`, `rounds[].verdicts`, `rounds[].guesser_output`, `counters.forced_passes`):

1. Game 1 (筒仔米糕, card-753f27f6). The entry says the Guesser "twice guessed bamboo tube rice before finally landing on the correct answer, the smooth batter cake, in round 6" and resolves to "lead with the batter or custard texture" next time. The guesses are right (竹筒飯 at 0.1 in rounds 3 and 5, 米糕 at 0.8 in round 6). The dish is not: 筒仔米糕 is glutinous rice with visible grains, and every description the Describer wrote in the game calls it a homogeneous flour batter with "no individual grains visible" (rounds 1, 4, 6). How this happened, from what the prompt shows the Describer: the card gives names and forbidden words only (`SPEC.md` State table, the three Describer rows: official name and aliases, English names, forbidden words; no attributes), the forbidden words are glutinous, sticky, tube, steamed, rice, pork, and one English name is "Tube rice pudding"; with rice and glutinous forbidden, the model reached for "flour batter" and took "pudding" literally. The Challenger judges fit against the distractors, not facts (`[R34]`), and passed round 4 and 6's descriptions; the Guesser's lookups were on "bamboo" and "paste" and it guessed the alias 米糕. The H prompt then told the Describer "right guess" (Disclosure rule), so the entry records the batter framing as what won. The game-6 summary carries it forward as "Game 1 (smooth batter cake)". A lucky win wrote a mistaken picture of the dish into long-term memory, and the mechanism did exactly what it is built to do: it keeps what the model believes.

## Remedies the author may consider, each with what it would touch

None of these is proposed as M6 work. They are listed so the decision can be made before M7's V3 batch, which is the last point at which a prompt change costs nothing (`SPEC.md` M7 runs the forty V3 games on whatever prompts exist, and the memory accumulates across them, so a change mid-batch invalidates the batch; after M7 the only remedy is a second V3 run).

- (a) The forced pass (Describer item 2): telling the Describer in its H prompt which description reached the Guesser by a forced pass, with the third verdict's reason, would let the entry weigh it. That is a new slot or a marked line in `prompts/describer_memory.txt` filled from State (the third verdict is in `rounds[].verdicts`, not in `rejected`), so a code change with its test, V3 only, and a check against the Disclosure rule's wording. Alternatively, accept it: the Describer learned from what it was told, and what it was told was true.
- (b) The mistaken picture of the dish (item 1): the Describer has no facts about the dish beyond its names, so nothing in the prompt can contradict "flour batter" when the card says main_ingredients Rice. Showing the Describer the card's `attributes` would do that, and is a `SPEC.md` change (the State table's Describer rows and Information isolation), touching every variant's Describer; it is not a leak (the Describer already holds the card) but it changes what all four variants describe from, so it must land before any batch. Alternatively, accept it: a memory that faithfully stores a confident mistake is itself a result for the report.
- (c) The Guesser's copied summary (Guesser item 2): a sentence in `prompts/guesser_memory.txt`'s entry-and-summary task forbidding the summary to repeat sentences of the entries that stay, and asking for generalizations. Touches V3 only. The current behaviour costs tokens, not correctness, and num_ctx is far from full.
- (d) Nothing: the seven games show the mechanism working as specified; the quality observations become M8's material.

Whichever is chosen, the prompt files are the author's (`prompts(<role>)` commits), and any change to them before M7 should be followed by a few V3 games from empty memory so M7 does not discover the effect forty games in.
