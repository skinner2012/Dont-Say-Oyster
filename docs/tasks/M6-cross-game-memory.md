# M6 — Build the cross-game memory needed for V3

## Goal & exit criterion

See `SPEC.md`, Milestones, M6. Do not copy the bullets here; they go stale.

**Exit criterion:** Done when a V3 game reads the previous game's memory files, the memory appears in the Describer's and Guesser's prompts, and new files are written at game end.

- **Real:** V3 runnable end to end: memory files, node H with its prompts, the Check rule, the memory block in the B and E prompts, the toggle with F → H and the record's memory fields, and seven live V3 games with the num_ctx check read over them.
- **Absent:** the batch script, crash recovery, and metrics (M7); prompt wording beyond a first draft (the author's `prompts(<role>)` commits); models, temperature, thinking (M5); the V3 report (M8); any change to how V0–V2 play.

## How to use these tickets

T1 → T2 → T3 → T4 → T5 → T6, one implementer at a time in the main checkout on `m6-cross-game-memory`. The dependency graph is narrower than the line: T4 needs only T1, and T5 needs T3 and T4; the line puts T4 after T3 so the two Fable tickets (T3, T5) are not split by an Opus ticket, nothing more. T1–T5 are code tickets accepted by tests with scripted model outputs (`docs/tasks/TEMPLATE.md`, Field rules); T6 is the live ticket, accepted by the record it leaves, never by the quality of the games or of the memory entries. One ticket, one commit, with the usual exceptions: T6's records land as they come (one commit per game or several games together), the two Decision lines are the author's (T5's token count, filled before this file's first commit; T6's num_ctx, filled in its own docs commit after the games), audit fixes and Status updates are their own small commits, and Status becomes done only after the audit closes. The two author decisions sit on Decision lines inside T5 and T6 rather than in decision tickets of their own (`docs/tasks/TEMPLATE.md`, Cutting tickets from the backlog): the convention since M4's T5 and M5's T1–T4, kept here because each decision is one line and T5's must be made before T5 is dispatched while T6's can only be made after T6's games.
